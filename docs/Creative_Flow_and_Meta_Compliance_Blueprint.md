# Creative Flow & Meta Compliance Blueprint

**Purpose:** The end-to-end operating system for producing a creative — from *why it exists* to a finished, compliant, multi-size, animated post. Built to run **model-to-model today** (each stage is a copy-paste instruction block) and to **collapse into one model / one click** later (Part F).

**Companion document:** *Social Media Creative Design Standards* (the design rulebook this blueprint executes). This blueprint = the process; the Standards = the craft.

**The spine of this system:** **GOAL → KNOWLEDGE → AMPLIFY.** Nothing is designed before the goal is fixed and the education layer exists. Trust is built by proving deep product knowledge *first*; hooks and sales only convert on top of that foundation.

---

## Part A — The Governing Brief

*The single most important object in this system.* This brief travels with the creative through **every** model. It is what stops your vision from drifting as work passes hand to hand. Fill it once per creative (or once per campaign, with per-post overrides). Every model receives it.

```
=================== GOVERNING BRIEF ===================
PROJECT:            [client / brand name]
CREATIVE ID:        [project_type_ratio_stage_version]  e.g. sunwa_launch_9x16_master_v1

1. REQUIREMENT / REASON
   Why this creative exists (one line):

2. GOAL  (pick ONE primary)
   □ Awareness  □ Education/Trust  □ Leads  □ Sales  □ Retention  □ Event/Register
   The single objective this creative must achieve:

3. BRAND GUIDELINES
   Logo file:            Colors (hex):            Fonts:
   Voice/tone:           Niche:
   Company watermark asset (for final stamp):

4. KNOWLEDGE BASE  (the education layer — the trust foundation)
   Product/service:
   Core USPs (2–4):
   Key features / proof points:
   What the client must believe to trust us:

5. SEQUENCE POSITION  (see Part B)
   □ L1 Education  □ L2 Hook  □ L3 Sales/Discount/FOMO  □ L4 Festival/Retention
   This post's job in the sequence:

6. MASTER & OUTPUTS
   Master ratio:        9:16 (default)     [override only with reason]
   Size set needed:     [see Part C, Stage 5 — default 6-size set]
   Animated?  □ No  □ Yes → duration ___ sec, animation intent: [Part C, Stage 6]

7. COMPLIANCE FLAGS
   Paid/boosted?  □ No  □ Yes (enforce 20% text rule)
   T&C required?  □ No  □ Yes (offer/price/claim present)
   Target platform(s):
   Generation tool watermark risk?  □ No  □ Yes → tool: ______  (see Part D)
=======================================================
```

**My input — why this matters:** your process already produces a "locked creative," but the *reasoning* behind it (goal, knowledge, sequence role, compliance) usually lives in your head. When you hand off to independent models, that context is lost and each model guesses. The Governing Brief makes the context portable. **This is the object you preload into every automated platform.**

## Part B — The Content Sequence Logic (Goal → Knowledge → Amplify)

Creatives are **not** produced in isolation — they're produced as a **sequence**, in a fixed order, because trust must precede selling.

| Layer | Type | Job | Publishes | Playbook (Standards §5) |
|---|---|---|---|---|
| **L1** | **Education / Knowledge** | Prove deep product/service knowledge. Build trust + reference material clients rely on. | **FIRST** | §5.1 Education |
| **L2** | **Hook** | Grab attention, create desire — now that credibility exists. | After L1 exists | §5.2 New Product / §5.4 FOMO |
| **L3** | **Sales / Discount / FOMO** | Convert the warmed, trusting audience. | On top of L1–L2 | §5.3 Sales / §5.4 FOMO |
| **L4** | **Festival / Occasion / Retention** | Warmth, loyalty, staying top-of-mind. | Ongoing | §5.5 Festival / §5.7 Testimonial |

**The rule:** *You cannot skip L1.* A hook or sale published before the education layer exists has nothing to land on — the client isn't convinced the brand knows its product, so there's no trust, and without trust there's no sale or retention. Education is the ground floor; everything else is built above it.

**Worked example — New Product Launch:**
1. **L1 (first):** carousel/posts explaining the product, its features, and USPs — the deep-knowledge foundation. *(Published first so the audience has real material to refer to.)*
2. **L2:** hook posts that create desire, now credible because L1 established expertise.
3. **L3:** the offer/discount/launch-day FOMO.
4. **L4:** festival tie-ins, testimonials, retention posts.

**My input — plan the whole sequence up front.** When you hand a campaign to automation, don't feed it one post — feed it the **full sequence plan** (L1→L4) with the knowledge preloaded, so every downstream model already knows its post's role and the shared knowledge base. This is exactly your stated end-state; formalize it as "one brief, full sequence."

## Part C — The Stage-by-Stage Pipeline

Seven stages. **Each block is written so you can paste it directly as an individual model's instruction today.** Every stage ends in a **GATE** — nothing broken passes downstream (garbage propagates and multiplies across resize + animation).

---

### STAGE 1 — Strategy & Brief
**Role:** Define the reason, goal, and knowledge before any creative exists.
**Input:** Raw request from you / client.
**Do:**
- Fix the ONE goal (Brief §2).
- Assemble the knowledge base / USPs (Brief §4) — this is the L1 education source.
- Set the sequence position (Part B) and outputs.
**Output:** A completed **Governing Brief**.
**GATE:** Goal is singular and clear · knowledge base is real (features + proof), not filler.

---

### STAGE 2 — Concept & Copy  *(the concept model)*
**Role:** Turn the brief into locked messaging and the creative concept. **This is where copy is locked before a single pixel is drawn.**
**Input:** Governing Brief.
**Do:**
- Select the correct **playbook** for the sequence position (Standards §5).
- Write **locked copy** by tier: Title/Headline, Subtitle, Communication, Detail, T&C.
  - Paid? Headline ≤ **5–7 words**; detail copy goes to the caption, not the image.
- For L1: structure the education content (steps/features/USPs, save-worthy).
- Define the **concept**: layout intent, focal element, energy, palette direction (per niche map, Standards §6).
- **Write the animation intent here** (even for a static-first post) — the hook beat, what moves, the end-card CTA. *(This model owns animation direction; the video model should not have to invent it.)*
**Output:** Locked copy sheet + concept description + animation intent, appended to the brief.
**GATE:** Treatment matches intent (sale ≠ education) · copy is final and proofed (spelling, currency, dates, codes) · one focal message identified.

---

### STAGE 3 — Master Design (9:16)  *(the design model)*
**Role:** Build the locked hero creative in the sovereign master ratio.
**Input:** Brief + locked copy + concept.
**Do:**
- Design at **9:16, 1080 × 1920** at full detail (Standards §4.4 — 9:16 is master; vertical-first prevents stretch damage later).
- Apply the full typography hierarchy and size bands (Standards §3), safe margins (§4.1), Story/Reel safe band `y = 250 → 1670` (§1.5).
- Make the money message the single dominant element (§4.2).
- Place logo per §4.3.
**Output:** Locked **9:16 master** creative + a layered/source file if possible.
**GATE:** Run the **Pre-Flight Checklist** (Standards §8) on the master. It must pass **before** it goes to resize/animation.

---

### STAGE 4 — Watermark Flag & Clean  *(checkpoint — see Part D)*
**Role:** Detect any platform-injected watermark before it propagates into 6 sizes and a video.
**Input:** Master creative (and any AI-generated assets used in it).
**Do:**
- Inspect every AI-generated element for a **platform watermark** (e.g. Grok on lower tiers, other gen tools).
- If found → **raise the flag** in the brief: which asset, where the mark sits, size.
**Output:** Clean master, **or** master + a **Watermark Flag Report** (asset, location, recommended handling).
**GATE:** No unflagged foreign watermark leaves this stage. If flagged, the handling instruction is attached for the final editor.

---

### STAGE 5 — Multi-Size Derivation  *(the resize model)*
**Role:** Derive the full size set from the master — by **reframing, never stretching**.
**Input:** Locked 9:16 master + brief.
**Do:** Derive the standard **6-size set** using Standards §4.4 (reframe: reposition, uniform rescale, re-flow) and §4.5 (step-down: fewer/bigger as it shrinks). **Logos and products keep locked aspect ratio always.**

| # | Ratio | Pixels | Primary use |
|---|---|---|---|
| 1 | 9:16 (master) | 1080 × 1920 | Reels, Stories, Shorts, TikTok, WA status |
| 2 | 4:5 | 1080 × 1350 | Instagram / Facebook feed |
| 3 | 1:1 | 1080 × 1080 | Feed, carousel |
| 4 | 16:9 | 1920 × 1080 | YouTube, X, LinkedIn, landscape |
| 5 | 2:3 | 1080 × 1620 | Pinterest, alt portrait |
| 6 | 1.91:1 | 1200 × 628 | Link / OG / feed link ads |

**Output:** 6 on-spec creatives, professionally named (`project_type_ratioXstage_v#`).
**GATE:** No stretching/distortion · each size passes safe-margin + step-down + minimum-floor checks · focal message still dominant at every ratio.

---

### STAGE 6 — Animation  *(the image→video model)*
**Role:** Convert the locked creative into a 10–15 sec animated post, following the concept model's animation intent.
**Input:** Locked creative (master or the target ratio) + the **animation intent from Stage 2**.
**Do (per Standards §7):**
- Hold each text line long enough to read (min ~2–2.5 s; ~0.3–0.4 s/word).
- **Hook in the first ~1.5–3 s** (autoplay).
- Design **sound-off first**; captions carry meaning.
- Keep all motion inside the safe band; no drift off-frame or into UI.
- **End on a static hold** with the offer/CTA + logo.
- Loop cleanly for short-form.
**Output:** 10–15 sec MP4 (H.264, ≤ ~1 GB, captioned).
**GATE:** Text readable at speed · hook lands in 3 s · legible on mute · ends on CTA hold · stays in safe zone throughout.

---

### STAGE 7 — Final QA & Watermark Stamp  *(the final editor)*
**Role:** Last gate. Enforce compliance, resolve any foreign watermark, apply your brand mark.
**Input:** All deliverables + any Watermark Flag Report.
**Do:**
- Run the full **Pre-Flight Checklist** (Standards §8) on every deliverable.
- **Resolve flagged watermarks** per Part D: remove / cover / crop — chosen by design, use, and size, **never by stretching or altering the locked design.**
- **Stamp the company watermark** over the (covered) foreign mark, in the safe zone at the logo size band.
- Verify compliance flags (20% text if paid, T&C present, correct sizes).
**Output:** Final approved creative set + video, release-named.
**GATE:** Every item passes Pre-Flight · zero foreign watermarks visible · company mark present and legal · brief goal satisfied.

## Part D — Watermark Protocol

*Your specific requirement, formalized as a governed checkpoint.*

**The situation:** some generation tools (e.g. Grok on lower tiers — currently your best photo-to-video for cost/speed/quality *with the right prompt*) stamp their own watermark unless you're on a higher tier. That mark must never reach a published asset.

**The rule chain:**
1. **Flag (Stage 4):** the design/QA phase must actively detect any platform-injected watermark and report it — which asset, exact location, size. **An unflagged watermark is a process failure.**
2. **Handle (Stage 7):** the final editor resolves it by the method that best fits the **design, use, and size**:
   - **Remove** — if cleanly separable from the design.
   - **Cover** — place an on-brand element or the company watermark over it.
   - **Crop** — reframe the canvas to exclude it *only if* it doesn't break the safe zone or focal composition.
3. **The inviolable law:** **never stretch, squash, or alter the locked/master design or the master prompt to hide a watermark.** The design integrity outranks watermark removal. If a clean method isn't possible, regenerate the asset — don't distort.
4. **Stamp:** place the **company watermark over** the (neutralized) foreign mark — in the safe margin, at the logo size band (5–8% of width, Standards §4.3), with correct clear space. Your mark replaces theirs; the design underneath is untouched.

**Watermark Flag Report (attach when raised):**
```
ASSET:        [file / element]
TOOL:         [e.g. Grok]
MARK LOCATION: [corner / coords]   SIZE: [approx]
RECOMMENDED HANDLING: □ remove □ cover □ crop
STAMP COMPANY MARK OVER IT?  □ Yes  → placement: [safe corner]
```

## Part E — Meta Compliance Quick-Rules

*Self-contained condensation of Standards §1 so this blueprint stands alone. Full detail in the Standards doc.*

- **Text-in-image (paid/boosted):** the hard 20% rule is officially retired, **but the algorithm still throttles text-heavy creatives** — reported ~**30–50% higher CPM** on text-heavy vs. text-light versions of the same ad. Keep visible text **≤ 20% of image area**. It's not font *size* Meta charges for — it's the **share of the image covered by text** (big/bold type just eats that share fast).
- **Image headline:** **5–7 words max**; push detail to the caption / primary-text field.
- **Sizes that cover ~90% of delivery:** 1080×1080 (1:1), 1080×1350 (4:5), 1080×1920 (9:16).
- **Story/Reel safe band:** keep all key elements in `y = 250 → 1670` (top ~250 px and bottom ~250–380 px are covered by UI).
- **Resolution:** ≥ 1080 px (below 600 px = throttled). JPG/PNG; video MP4/MOV H.264 30 fps, ≤ ~1 GB, **captioned** (feed is watched sound-off).
- **Export per ratio** — don't rely on one auto-cropped asset for high-stakes placements.
- *Re-verify Meta's official Ads Guide quarterly; placements change (e.g. IG Explore feed retired Jan 2026 → more Reels delivery).*

## Part F — The One-Click Future (Single-Model Master Prompt)

When one model can run the whole chain, paste this **master prompt + a filled Governing Brief** and it executes Stages 2→7 in order. Until then, the same numbered steps double as your per-model instructions.

```
====================== MASTER PROMPT ======================
You are an end-to-end creative production system. You take a Governing
Brief and produce a compliant, multi-size, animation-ready creative set,
following a fixed design standard. Obey every rule; never skip a stage.

INPUT: the Governing Brief below.
GOVERNING BRIEF:
{{paste completed Governing Brief}}

FIXED PRINCIPLES (never violate):
- Spine: GOAL → KNOWLEDGE → AMPLIFY. If this is an Education (L1) post,
  produce trust-building, reference-grade content. Hooks/sales (L2–L4)
  must assume the education layer already exists.
- Master ratio 9:16 (1080×1920). Derive all other sizes by REFRAMING
  (reposition, uniform rescale, re-flow) — NEVER stretch/distort.
  Logos and products keep locked aspect ratio always.
- Typography tiers (as % of canvas width): Logo 5–8% · Title 9–16% ·
  Subtitle 5–7% · Body 3.2–4.5% · Detail 2.4–3.2% · T&C 1.7–2.2%
  (floor 1.6% of width; never below ~18px on a 1080 canvas).
- Safe margin 6% of width all sides. Story/Reel keep key elements in
  y = 250→1670. ≤ 3–4 tiers visible; ≤ 2 typefaces; one bold per zone.
  Contrast ≥ 4.5:1 body / 3:1 large.
- Step-down: ≥1080 = 3–4 tiers · 600–1080 = 2–3 (bump body +1 band) ·
  <600 = hook + logo only.
- Treatment must match intent (flash sale ≠ education layout). The money
  message (offer/hook/product name) is the single dominant element.
- Paid/boosted: visible text ≤ 20% of image area; headline ≤ 5–7 words.
  T&C present if any offer/price/claim.
- Watermark: detect any platform-injected mark; remove/cover/crop by
  design+use+size; NEVER distort the design to hide it; stamp the company
  watermark over it in the safe zone at the logo size band.

EXECUTE IN ORDER:
1. CONCEPT & COPY: pick the playbook for the sequence position; write
   locked copy by tier (proofed); define layout, focal point, palette,
   and the animation intent (hook beat, motion, end-card CTA).
2. MASTER DESIGN (9:16): build the full-detail 1080×1920 master; make the
   money message dominant; place logo; keep everything in the safe zone.
3. WATERMARK CHECK: flag any foreign watermark + handling.
4. DERIVE SIZES: 9:16 · 4:5 (1080×1350) · 1:1 (1080×1080) ·
   16:9 (1920×1080) · 2:3 (1080×1620) · 1.91:1 (1200×628) — by reframing.
5. ANIMATE (if requested): 10–15s; hook in first ~3s; readable text holds;
   sound-off legible with captions; end on CTA hold; loop clean.
6. FINAL QA: run the pre-flight checklist on every output; resolve
   watermarks; stamp company mark; verify compliance flags.

OUTPUT: the locked 9:16 master, the 6-size set, the animated cut (if
requested), and a QA + compliance confirmation. Name every file
[project_type_ratio_stage_version].
===========================================================
```

**How to use today:** run Stage blocks (Part C) as separate model prompts; carry the Governing Brief between them; use the Watermark Flag Report at Stage 4→7. **The day a single model is capable, the same rules are already written as one prompt above** — paste brief, one click.
